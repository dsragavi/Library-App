Library-App
Smart Library Management App for coursework
Project Overview

The Smart Library Management App is a web-based application designed to provide a simple and user-friendly interface for browsing and managing library book information.

The application is developed using HTML, CSS, and JavaScript. It contains multiple pages that allow users to navigate between the home page, login page, registration page, My Books page, About page, and Contact page.

Objectives

* To create a user-friendly library website.
* To provide a home page for viewing library information and available books.
* To create login and registration pages for the user interface.
* To provide a My Books page for viewing book information.
* To make navigation between pages simple and convenient.
* To publish the website using GitHub Pages.

Technologies Used

* HTML – Structure of web pages.
* CSS – Styling, layout, and responsive design.
* JavaScript – Client-side interactions and functionality.
* GitHub – Source code management.
* GitHub Pages – Website hosting.

Main Pages

1. **Home Page:** Displays the main interface and library book information.
2. **Login Page:** Provides fields for users to enter their login details.
3. **Register Page:** Provides a form for new users to enter registration details.
4. **My Books Page:** Displays book information associated with the user interface.
5. **About Page:** Provides information about the application.
6. **Contact Page:** Displays contact information or a contact form, depending on implementation.

How to Use

1. Open the published website.
2. Navigate through the available pages using the navigation menu.
3. Browse the book information on the Home Page.
4. Open the Login or Register page to view and use the available forms.
5. Visit the My Books, About, and Contact pages.

Testing

The application should be tested for page navigation, form validation, layout, and browser compatibility. Actual test results are documented separately in `test-results.md`.

Deployment

The website is hosted using GitHub Pages. The published website URL can be added here after deployment.

Project Limitations

The current application is a front-end web project. Features such as database storage, secure user authentication, and live book borrowing or returning require additional implementation unless they are already supported by the code.

Conclusion

The Smart Library Management App demonstrates the development of a multi-page website using HTML, CSS, and JavaScript. It provides a foundation for a library management system and can be extended with additional features in the future.
