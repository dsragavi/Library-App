SDLC Workflow – Smart Library Management App

1. Planning

The project began by identifying the purpose of the Smart Library Management App. The goal was to create a simple website that provides library-related information and allows users to navigate between multiple pages.

2. Requirement Analysis

The main requirements were identified:

* Home Page for the main interface and book information.
* Login Page for entering login credentials.
* Register Page for entering registration details.
* My Books Page for viewing book information.
* About Page for project information.
* Contact Page for contact details or a contact form.

3. System Design

The page structure, navigation menu, forms, and book display areas were planned before development. A wireframe was used to represent the proposed layout, and workflow diagrams were prepared to explain the development process and user navigation.

4. Development

The website was developed using HTML, CSS, and JavaScript.

* HTML was used to structure the pages.
* CSS was used to style the interface and page layouts.
* JavaScript was used to implement client-side interactions.
* Separate files were organised for the different pages and supporting functionality.

5. Testing

The pages should be tested to verify navigation, form validation, page layout, and browser compatibility. Any errors found during testing should be corrected and the affected features tested again. The actual results should be recorded in `test-results.md`.

6. Deployment

The source files were uploaded to the GitHub repository. GitHub Pages was used to publish the website. The published URL should be checked to confirm that the pages and their linked assets load correctly.

7. Maintenance

After deployment, the website can be improved by correcting bugs, refining the interface, improving mobile responsiveness, and adding new features. Database integration and secure authentication may be considered for future development.

Conclusion

The SDLC process provides a structured approach to planning, designing, developing, testing, deploying, and maintaining the Smart Library Management App.
