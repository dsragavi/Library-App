Software Requirements Specification

1. Introduction

The Smart Library Management App is a web application designed to provide users with a simple interface for accessing library-related information and navigating between different pages.

2. Functional Requirements

FR1: Home Page

* The system shall display the application name and navigation menu.
* The Home Page shall display library information and book details available in the interface.
* Users shall be able to navigate to other pages.

FR2: Login Page

* The system shall provide input fields for login credentials.
* The page shall provide a Login button.
* The page shall provide a link to the registration page.
* Input validation and authentication shall work according to the implemented JavaScript functionality.

FR3: Registration Page

* The system shall provide fields for entering registration details.
* The page shall provide a Register button.
* Required-field validation shall be provided where implemented.

FR4: My Books Page

* The system shall provide a page for displaying book information.
* The page shall allow users to view the book details available in the application.
* Borrowing or returning functionality shall be included only if implemented in the code.

FR5: About Page

* The system shall provide information about the application and its purpose.

FR6: Contact Page

* The system shall display contact information or a contact form, depending on the implementation.

FR7: Navigation

* Navigation links shall connect the available pages.
* Users shall be able to return to the Home Page from other pages.

3. Non-Functional Requirements

Usability

The interface should be simple, clear, and easy to navigate.

Performance

Pages should load within a reasonable time under normal conditions.

Compatibility

The website should work in modern web browsers.

Responsiveness

The layout should adapt to desktop and mobile screen sizes where responsive styling is implemented.

Maintainability

HTML, CSS, and JavaScript files should be organised so that they can be updated easily.

4. Software Requirements

* A modern web browser.
* An internet connection to access the published website.
* GitHub account for repository management and GitHub Pages deployment.
  
5. Hardware Requirements

* A computer, laptop, tablet, or smartphone.
* Sufficient memory and storage to run a modern web browser.

6. Constraints

The application uses front-end technologies. Database integration, server-side processing, and secure authentication are outside the scope unless separately implemented.

7. Expected Outcome

A working multi-page library website with accessible navigation and the features implemented in the Home, Login, Register, My Books, About, and Contact pages.
